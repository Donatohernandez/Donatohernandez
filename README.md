# Hola, soy Donato

**Desarrollador Full-Stack | Automatización con IA · Backend · Integración de Sistemas**

Convierto procesos manuales en sistemas confiables impulsados por IA. Diseño automatizaciones, servicios backend y productos de extremo a extremo con n8n, Node.js, Supabase, OpenAI y Gemini.
